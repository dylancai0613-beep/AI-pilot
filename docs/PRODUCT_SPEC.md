# 华南出行成本迷你计算器：产品需求

## 一、项目目的

本项目是独立的 AI 自动开发试验项目，用于验证 Codex 是否能够：

1. 根据明确任务开发功能；
2. 自动运行程序和测试；
3. 根据真实错误日志修复问题；
4. 在测试通过后提交代码。

本项目不属于正式微信小程序，不得连接正式项目。

## 二、首版功能

页面提供以下输入：

- 出发城市
- 目的城市
- 出行人数

首版只支持以下城市：

- 广州
- 深圳
- 佛山
- 东莞

出行人数允许范围：

- 1 至 4 人

## 三、结果内容

查询后展示三种模拟交通方案：

1. 高铁
2. 长途汽车
3. 网约车

每种方案展示：

- 交通方式
- 总价格
- 人均价格
- 预计耗时
- 推荐标签

推荐标签包括：

- 最省钱
- 最快
- 多人更划算

## 四、业务规则

1. 出发城市和目的城市不能相同。
2. 出行人数必须是 1 至 4 的整数。
3. 网约车总价不随人数变化，人均价格等于总价除以人数。
4. 高铁和长途汽车总价等于单人票价乘以人数。
5. 所有数据均使用项目内置模拟数据。
6. 不调用地图、票务、支付或其他外部 API。
7. 查询失败时页面必须显示明确错误信息。
8. 页面不得白屏或静默失败。

## 五、技术范围

- 后端：FastAPI
- 前端：原生 HTML、CSS、JavaScript
- 后端测试：Pytest
- 页面测试：后续使用 Playwright
- 运行环境：Docker Compose

## 六、首版不做

- 用户登录
- 数据库
- 微信小程序
- 地图导航
- 真实票价
- 实时班次
- 购票功能
- 付费 API
- 云端部署
